# AGENTS.md

TransitAI / TransitMate Yangon: a TanStack Start (React 19 + TS + Vite) full-stack bus route finder for Yangon. Deterministic route engine in TS; two optional Python services (ML crowding, Prolog rules) live next to it.

## Commands

```sh
npm run dev        # Vite dev server (SSR)
npm run build      # production build
npm run lint       # ESLint 9 flat config
npm run format     # prettier --write .
npx tsc --noEmit   # typecheck (NOT wired as an npm script — run it manually)
```

There are NO tests (no vitest/jest/pytest and no config). Verify changes with `npx tsc --noEmit`, `npm run lint`, and `npm run build`.

Dual lockfiles exist: `bun.lock` + `package-lock.json`. The README installs with npm; `bunfig.toml` has `minimumReleaseAge = 86400`, so Bun installs can reject brand-new packages.

## Non-negotiables

- **The deterministic engine is the only thing that invents routes.** `src/lib/transit/engine.ts` (generalised Dijkstra) produces journeys; the AI layers in `src/lib/ai/` (travel-time predictor, crowding predictor, recommender) and the Prolog service only re-estimate, rank, and annotate journeys the engine already returned. Never let any "AI" code create bus numbers, stops, fares, or connections. Everything demo-shaped must be labelled `isDemo`/demo.
- **Note the live YBS dataset is real, not demo**: the default data source is the bundled YBS CSVs (`src/lib/transit/data/ybs/`, ~2k stops, ~118 routes), `source.isDemo: false`. The `supabase/schema.sql` demo network (30 stops, 6 routes) is a different dataset. `setDataSource()` in `src/lib/transit/data-source.ts` swaps sources; engine code only sees `TransitNetwork`.

## Architecture facts

- Server functions (`createServerFn`) are the RPC boundary: `src/lib/transit/transit.functions.ts`, `src/lib/ai/ai.functions.ts` (`planJourney` = the full pipeline), `src/lib/prolog/prolog.functions.ts`. Routing is file-based; read `src/routes/README.md` — no `src/pages/`, sole root layout is `__root.tsx`, dynamic segments are bare `$id`. `routeTree.gen.ts` is auto-generated — never edit it.
- Python services are optional. Every remote call (Zod-validated, 4s / 1.2s timeouts) falls back to a deterministic TS mirror, so `npm run dev` works with zero Python:
  - `ml-service/` (FastAPI, port 8001) implements only the **crowding** `/predict` contract. `.env` points BOTH `ML_PREDICTOR_URL` and `ML_CROWDING_URL` at it, so travel-time requests to it fail validation and silently fall back to the demo heuristic — expected behavior, not a bug.
  - `prolog-service/` (FastAPI + SWI-Prolog, port 8002); `ybs_facts.pl` is generated by `load_ybs.py` from the same CSVs; `bus_routes.pl` has hard-coded fallback routes. Its `/execute-query` endpoint runs arbitrary Prolog — don't weaken the disallowed-predicate blacklist in `app.py`.
- `src/lib/prolog/prolog-service.ts` and `src/lib/ai/travel-time-predictor.ts` / `crowding-predictor.ts` are the swap points for external services; each has a local deterministic fallback.

## Gotchas

- **`vite.config.ts`:** `tanstackStart()` already wires the router plugin + code-splitter. Do NOT also register `tanstackRouter()` — double-registering breaks the build (`TSRSplitComponent is not defined`), per the comment there.
- **`src/start.ts` must stay.** Defining it disables TanStack Start's auto-installed CSRF; the file re-adds CSRF for `serverFn` handlers explicitly. Deleting it silently removes CSRF protection.
- **h3 swallows handler errors** into `{"unhandled":true,"message":"HTTPError"}` bodies. `src/server.ts` + `src/lib/error-capture.ts` recover the real stack (wrapped `console.error`, 5s TTL). Preserve this machinery and `normalizeCatastrophicSsrResponse()`.
- ESLint bans the `server-only` package (use `*.server.ts` / `@tanstack/react-start/server-only`). `@typescript-eslint/no-unused-vars` is off.
- `tsconfig.json` is strict in non-default ways: `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noPropertyAccessFromIndexSignature`, `noUncheckedSideEffectImports`. Expect to handle possibly-undefined indexing and optional props explicitly.
- Myanmar (Burmese) text in the YBS CSVs renders as mojibake in most consoles (8-bit code page); the app uses the English columns.
- `.env` is committed and holds only the three service URLs.
